# wipe_done

> 2019 年的 Flutter 任务清单习作，作为历史项目保留。

应用支持新增、编辑、删除、标记完成/星标任务以及本地主题切换。任务以 JSON 形式写入设备本地的 `todolist.txt`；没有账号、后端或同步服务。

## 当前状态

- `pubspec.yaml` 约束 Dart `>=2.1.0 <3.0.0`，项目早于 null safety。
- 依赖 `path_provider 1.x`、`shared_preferences 0.5.x` 等早期包版本。
- 尚未迁移或验证当前 Flutter、Dart、Android 或 iOS 工具链，也没有当前可下载的发布版。
